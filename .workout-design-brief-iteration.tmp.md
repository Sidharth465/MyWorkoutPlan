# Design iteration brief: General muscle focus, no SVG

## Objective and audience
Revise the existing personal workout-plan page in response to owner feedback: they dislike the "muscle head targeted" presentation and explicitly do not want SVG. Keep the existing static workout plan and make this area simpler, clearer, and more approachable.

## Required changes
- Replace every exercise table heading "Exact Muscle Head Targeted" with "Muscles Worked".
- Remove per-head, anatomical-subdivision, and exact-head emphasis from the exercise focus presentation. Describe broad, familiar muscle groups only (for example: chest, shoulders, arms, back, glutes, legs, calves, core).
- Preserve the exercise list, prescriptions, alternatives, demo links, and useful coaching cues. Do not lose other page content or change the training plan.
- Retain the requested visual muscle illustration per exercise, but absolutely do not use SVG: no SVG file, inline SVG, fetched SVG, or SVG-backed CSS. Create a small, local, dependency-free raster illustration using Canvas 2D (or equivalent raster-only method), with broad body regions highlighted by primary and supporting roles. Provide text labels and an accessible name/alternative so the visuals remain understandable.
- Remove the SVG muscle map asset and any SVG-based loading or CSS. Ensure all muscle focus diagrams work when the static page is opened/deployed, and explain Canvas-based local asset organization in README.

## Aesthetic direction
Continue the existing editorial training field-guide design: warm paper background, ink/navy text, terracotta primary focus, blue supporting focus. Make the workout focus section compact and immediately understandable, without clinical/detail-heavy "head" terminology. Keep responsive horizontal table scrolling and existing page conventions.

## Typography and colors
Use existing local/system typography and CSS variables from `styles.css`. Keep strong contrast, restrained labels, and clear primary/support colors.

## Technical constraints and preservation
- Existing project is a dependency-free static GitHub Pages site.
- Preserve the existing user-owned changes in `index.html`, `styles.css`, README, and existing exercise mappings; edit surgically.
- No remote image services or externally hosted muscle illustrations.
- Keep accessible semantics and avoid adding packages/build tooling.
